# 01 - מפת הפרויקט

## התמונה הגדולה

LingoFlix מורכב משני יישומים:

```text
טלפון Android - Kotlin + Compose
        |
        | HTTP דרך Retrofit
        v
שרת Python - FastAPI
        |
        +-- מסד נתונים
        +-- חידונים
        +-- SRT
        +-- AI
        +-- מדיה
```

## תיקיות מרכזיות

| תיקייה | תפקיד | סטטוס |
|---|---|---|
| `app/` | קוד אפליקציית Android | חובה |
| `backend/` | שרת Python | נחוץ לפיצ'רים שמבוססים על שרת |
| `gradle/` | כלי בנייה של Android | חובה לבנייה |
| `docs/` | מסמכי הלימוד בעברית | שימושי, לא נצרך בהרצה |
| `.idea/` | הגדרות Android Studio | לא ללמוד כרגע |
| `.artifacts/` | תוכניות ותוצרים של כלי פיתוח | לא נצרך בהרצה |
| `app/build/` | תוצרים שנוצרו בבנייה | לא ללמוד ולא לערוך |

## שתי שאלות שצריך לשאול בכל קובץ

1. האם הקובץ רץ בטלפון או בשרת?
2. האם הוא מחליט משהו, או רק מציג/מעביר מידע?

## זרימת שימוש עיקרית

```text
בחירת סרטון
 -> שמירת קובץ בטלפון
 -> קריאת SRT
 -> הפעלת נגן
 -> מציאת משפט לפי זמן
 -> יצירת תרגיל
 -> בדיקת תשובה
 -> עדכון XP / progress
```

## זרימת שרת

```text
HTTP request
 -> Router
 -> Schema validation
 -> Service
 -> Database model
 -> JSON response
```

## מה לא ללמוד כרגע

- `app/build/`
- `.gradle/`
- `kspCaches/`
- `intermediates/`
- `.kotlin/errors/`
- רוב קבצי `.idea/`
- תמונות ואייקונים

הם חשובים לכלי הבנייה או ל-IDE, אבל אינם הלוגיקה של המוצר.
